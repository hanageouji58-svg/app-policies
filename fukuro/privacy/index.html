要点

  • 記録の削除は、アプリ内からいつでも行えます。

1. 端末内だけに保存する情報

次の情報は、お使いの端末内のアプリの保存領域にのみ保存します。ランキングに関する項目を除き、外部へ送信しません。アプリを削除すると消去されます。

  • プレイ記録（星、ベストスコア、レシート、実績）
  • 設定
  • ブロックしたプレイヤーの一覧

2. 全国ランキングで扱う情報

全国ランキングは任意です。プレイヤーが連続レジから参加を選んだ場合だけ、次のとおり情報を扱います。

匿名アカウント

参加時に、Firebase Authentication（Google）で匿名アカウントを作成します。ランダムなIDが付与されるだけで、名前・メールアドレス・電話番号は使いません。

保存する情報（Cloud Firestore）

ランキングの運用のため、Cloud Firestore（Google Firebase）に次の情報を保存します。

  • 連続レジの自己ベストスコアと、その更新時刻
  • 星の数（0〜120）、実績の数（0〜40）と、その更新時刻
  • プレイヤーが店員名を設定した場合は、その店員名、内部の版ID、更新時刻（設定しない場合は、匿名IDから作られる自動の名前を表示します）
  • 他のプレイヤーの名前についてプレイヤーが送った通報（対象のID、通報者のID、通報された名前とその版、理由、時刻）
  • 旧バージョンでは、名前の申請

他のプレイヤーに公開される情報

順位、店員名（または自動の名前）、ベストスコア、星の数、実績の数が、ランキングを見る他のプレイヤーに表示されます。通報の内容は公開されず、運営者だけが確認できます。

3. 利用目的

  • 全国ランキングの表示
  • 不適切な名前（攻撃的な表現、個人情報、なりすましなど）による不正利用の防止
  • 通報への対応

運営者は、不適切な店員名を削除することがあります（削除後は自動の名前に戻ります）。また、名前の設定を停止することがあります。

4. 外部サービス（Google / Firebase）

ランキングの提供には、Google の Firebase（Firebase Authentication、Cloud Firestore）を使用します。サービスの提供に必要な範囲で、Googleが IP アドレスなどの技術的な情報を処理します。取り扱いはGoogleのプライバシーポリシーに従います。

  • Firebase のプライバシーと情報セキュリティ
  • Google プライバシー ポリシー

5. 第三者への提供・販売

情報を販売しません。広告には利用しません。サービス提供者であるGoogle以外の第三者へは提供しません。

6. 記録の削除・参加の中止

ランキングへの参加は、いつでもやめられます。

  • アプリ内で削除：「設定」→「全国ランキングの記録を削除」を選ぶと、スコア、プロフィール（星・実績・店員名）、名前の申請、匿名アカウントをまとめて削除します。
  • メールで依頼：panelpower.app@gmail.com からも依頼できます。

端末内のレシートは、削除後も端末に残ります。すでに送信した通報は、不適切な名前への対応のため、運営者が保管します。
